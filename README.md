# BeautyOS

Painel operacional de uma casa. Uma conta é um negócio.

A documentação de produto está em `docs/`. Este repositório começa com um app que sobe e responde em `/health`. A operação (agenda, comanda, fichas) ainda não está implementada.

O banco é um Postgres só deste projeto, no EasyPanel. Não usa o banco do app-barbearia.
